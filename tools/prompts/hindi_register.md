# Hindi register: tatsama-leaning standard Hindi

Shared by `transcript_to_blog.txt` and `transcript_to_chapter.txt`, and read by
`tools/check_hindi_register.py`. The lists use the form `word → replacement`, one per line; keep
that form so the script can read them.

Write tatsama-leaning standard Hindi: dignified and suited to spiritual teaching, but natural to
read, never archaic. A chapter may sit a little higher in register than a blog.

## Rule 1: always replace

These words carry the subject of the teaching; use the replacement every time.

- ज़िंदगी → जीवन
- जिंदगी → जीवन
- दुनिया → संसार / जगत
- इंसान → मनुष्य
- दिल → हृदय / मन
- कोशिश → प्रयास
- असर → प्रभाव
- फर्क → अंतर
- फ़र्क → अंतर
- सिर्फ → केवल
- सिर्फ़ → केवल
- खुद → स्वयं
- ख़ुद → स्वयं
- ताकत → शक्ति
- ताक़त → शक्ति
- इलाज → उपचार
- मकसद → उद्देश्य
- मक़सद → उद्देश्य
- बदलाव → परिवर्तन
- सवाल → प्रश्न

## Rule 2: allow where natural

Everyday standard Hindi that every reader uses. Prefer the tatsama form in headings and
takeaways, but do not force it in running text.

- तरह → प्रकार
- शायद → संभवतः
- हमेशा → सदा
- आसान → सरल
- रिश्ता → संबंध
- रिश्ते → संबंध
- रिश्तों → संबंधों
- कीमत → मूल्य
- क़ीमत → मूल्य

## Rule 3: never use (archaic)

Do not use these; write the plain word instead.

- कदाचित् → शायद / संभवतः
- कदाचित → शायद / संभवतः
- किंचित → थोड़ा
- अतः → इसलिए
- तथापि → फिर भी
- सुगम → सरल

## Rule 4: headings and search words

Headings and the focus keyword follow the words people actually search for (from the SEO
report), even where that is the everyday form of Rule 2.

## The speaker's name

Refer to the speaker as "आचार्य जी" (two words, with a space). Use the full name
"आचार्य उपेंद्र जी" once, where he is first introduced, if the text introduces him. Use गुरुजी,
गुरुदेव or सद्गुरु only for someone else (for example his own Guru) or where the transcript
itself uses them for a general Guru, never as another name for Acharya Ji.

- आचार्यजी → आचार्य जी
- आचार्य श्री → आचार्य जी
- गुरुजी → आचार्य जी (if it means him)
- गुरु जी → आचार्य जी (if it means him)
- गुरुदेव → आचार्य जी (if it means him)
