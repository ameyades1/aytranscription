## 12. SEO checklist

### Keywords
- [ ] Hindi and English each have a focus keyword
- [ ] The focus keyword isn't used by another post (no cannibalization)
- [ ] 2–4 secondary keywords per language
- [ ] Hindi and English keywords researched separately, not translated; Hinglish variants considered
- [ ] Focus keyword taken from wording the article already uses
- [ ] If people search a different wording, it is in the secondary keywords and the mismatch is flagged
- [ ] Priority given as High / Medium / Low, based on intent and competition; no invented numbers

### Focus keyword placement (SureRank)
- [ ] In the SEO title
- [ ] In the meta description
- [ ] In the body text
- [ ] In the URL slug (English keywords)
- [ ] Within the first 100 words (preferred)

### SEO title
- [ ] Present in both languages, ≤ 60 characters
- [ ] Keyword near the start
- [ ] Faithful to the talk, no clickbait

### Meta description
- [ ] Present in both languages, ≤ 160 characters
- [ ] English is 140–155 characters
- [ ] Gives a clear reason to click

### URL slug
- [ ] Lowercase Latin, hyphenated, unique across posts
- [ ] Short enough that the full URL stays ≤ 90 characters

### Headings
- [ ] At least one subheading (H2)

### Images
- [ ] Every image has alt text in both languages
- [ ] Alt text is descriptive, in the post's language, based on looking at the image
- [ ] Captions add meaning (not a repeat of the alt text or title)

### Internal linking
- [ ] Links point only to real posts, never to the same post
- [ ] Anchor text is a natural phrase from the body (not a heading or verse)
- [ ] 3–5 in-text links per language
- [ ] One "Also read" link, placed after the section it extends best
- [ ] 3 related posts at the end, the ones that suit this reader best

### Category and tags
- [ ] One category, from the approved 14
- [ ] 3–6 tags per language
- [ ] No tag repeats a category name
- [ ] Existing tags reused; no near-duplicates
- [ ] Each tag can be shared by at least 3 posts
- [ ] No broad labels that only restate a category
- [ ] Series tags named exactly as the series
- [ ] `festivals` only when the post is about the festival itself; Pitru topics in `pitru`

### Structured data (in this report, not on the page)
- [ ] One JSON-LD block per language: BlogPosting, Person, Organization, VideoObject (if there is a video), BreadcrumbList
- [ ] Hindi and English versions linked as translations

### Content trust
- [ ] Titles, metas and snippets faithful to the talk
- [ ] No unsupported scriptural claims
- [ ] Health promises, fear-selling and attacks on other traditions flagged

### Not covered
- Live broken links (internal links only work once the linked post is published)
- Canonical and Open Graph tags (SureRank adds these itself)
