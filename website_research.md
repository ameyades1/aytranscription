# Website research: WordPress, Astra and how comparable sites are built

Notes gathered on 2026-10-23 while planning a custom WordPress theme for the Antar Yog blog. Stack
findings come from each site's homepage HTML and response headers on that date; sites change, so
re-check before relying on them.

## Plan: an Antar Yog WordPress theme identical to the repo's blog pages

Goal: a WordPress theme that reproduces the pages generated by `tools/template/blog_page.py` and
`tools/template/blog.css`.

### What has to be reproduced

- **Header**: logo, nav, Donate button, CSS-only mobile menu (checkbox toggle), language switch.
- **Hero**: breadcrumbs, category label, title, ❖ ornament, byline (Acharya Ji's photo, name,
  reading time), action buttons.
- **Body**: two columns. Article on the left (figures with captions, verse blockquotes, Also read
  box, YouTube video card, Further reading grid); sticky author-bio sidebar on the right.
- **CTA band** (courses and a second button), then the **footer** (brand, motto, social icons,
  contact, legal line).

### Main design decision

The repo puts both languages on one page and switches with JS (`lang-block` + `hidden`).
WordPress, through Polylang and smd-importer, has one post per language. The theme follows
WordPress: the language switch links to the Polylang translation (`pll_the_languages()` or the
existing `[smd_lang_switch]`). It looks the same, but the switch goes to another URL.

### Steps

1. **Scaffold a classic PHP theme** in `wordpress-theme/antaryog/`: `style.css`, `functions.php`,
   `header.php`, `footer.php`, `single.php`, `index.php`/`archive.php`, `page.php`, `404.php`.
   Classic PHP over a block theme, because the markup can be copied from `blog_page.py` almost line
   for line.
2. **CSS**: copy `blog.css` in as the theme stylesheet so class names stay the same; enqueue the
   same Google fonts; add a small layer for WordPress markup (`wp-block-image`, `figcaption`,
   `wp-block-quote`, `.wp-block-embed`, the importer's Also read group).
3. **Templates**: port `site_header()`/`site_footer()` (nav as a menu location; social, contact
   and motto as Customizer settings). Port `build_lang()` to `single.php`: breadcrumbs, primary
   category label, title, byline with reading time computed like `read_minutes()` (Hindi digits for
   `hi`), `the_content()` plus sticky author aside, Further reading grid, CTA band (strings
   translated through Polylang).
4. **Data the theme needs**: check which `seo.json` fields the importer writes (hero image, YouTube
   ID, Further reading links, category label). Further reading probably needs adding, for example
   as `smd_related` post meta.
5. **Importer alignment**: have `smd-importer` emit the same class names as the static page
   (`figure`, `also-read`, `video`, `related`) so one CSS file styles both.
6. **Archive/home**: a card grid matching `tools/template/gallery_page.py`.
7. **Verify on `~/wordpress`**: activate the theme instead of Astra (`setup_astra.sh` stays as the
   fallback), re-import 2–3 talks with `wp smd import`, compare Playwright screenshots of the static
   page and the WordPress page at desktop and phone widths, in Hindi and English.
8. **Ship**: a `build_zip.sh` like the plugin's, a WORKFLOW.md section, then upload to the live
   site (only after confirming).

## What is Astra?

Astra is a WordPress **theme** (the layer that decides how a site looks), made by Brainstorm
Force, who also make Spectra. It is one of the most-installed themes on WordPress.org (over a
million active sites).

Why people use it:

- Lightweight and fast by default, which helps page speed and SEO.
- Customized through settings rather than code (header, footer, colours, fonts, layouts).
  `~/wordpress/setup_astra.sh` reproduces the live blog this way, through `astra-settings`.
- Works with page builders: Elementor, Spectra, Beaver Builder, the block editor.
- One-click starter templates; free, with a paid Pro tier.

Downside: its markup is generic. Settings plus custom CSS (`live-custom.css`) get close to the
static blog design, but not identical; a custom theme gives exact control.

## How much of the web runs on WordPress?

"33%" is out of date (about right around 2019). W3Techs surveys in recent years put WordPress at
**about 43% of all websites** and **about 60%+ of sites using a known CMS**. Growth has flattened as
Shopify, Wix and Squarespace grow. Check w3techs.com for the current figure.

Well-known WordPress sites (may have changed since): TechCrunch, TIME, Variety, Rolling Stone, The
Hollywood Reporter (many on WordPress VIP, Automattic's enterprise hosting); Meta's newsroom,
Microsoft's blogs, Sony Music, The Walt Disney Company; whitehouse.gov (WordPress since 2017).

## Free hosting options

| Option | Custom theme/plugins? | Notes |
|---|---|---|
| Static export → GitHub Pages | Yes, built locally | Already in use: `export_static.sh` (Simply Static) exports the local WordPress into `output/wp/`; pushing `main` deploys. Free and fast; no comments, search or forms. Best fit for showing the new theme. |
| Cloudflare Pages / Netlify / Vercel | Yes, static | Same idea, plus automatic preview URLs per branch. |
| WordPress Playground | Yes | Real WordPress in the browser; shareable link or blueprint. Each visitor gets a temporary copy; demos only. |
| WordPress.com free plan | No | No custom themes or plugins without a paid plan. |
| Free PHP hosts (InfinityFree etc.) | Yes | Slow, ads or limits, unreliable. Quick tests only. |

## Showing mockups and getting feedback

- **Comments on the page**: claude.ai Artifacts (shareable private link with comments); Vercel
  preview deployments (comment toolbar); Markup.io, Pastel, BugHerd (pin comments on any URL).
- **Design mockups**: Figma (free tier), with comment threads.
- **Outside feedback**: Reddit (r/web_design, r/WordPress, r/UXDesign); Dribbble/Behance (more
  showcase than critique); WordPress.org forums for technical questions.

Suggested route: build the theme locally, export with Simply Static to GitHub Pages or a Cloudflare
Pages preview, and share that link through Markup.io or an Artifact for comments.

## How comparable sites are built

| Site | What it is | Stack | Hosting |
|---|---|---|---|
| antaryogfoundation.in | Antar Yog main site | Custom Laravel (PHP) app; Tailwind, Bootstrap 5, Alpine.js, jQuery | Caddy behind BitNinja firewall |
| blogs.antaryogfoundation.in | Antar Yog blog | WordPress 7.1.3, Astra, Elementor 4.3.5 | Cloudflare |
| isha.sadhguru.org | Isha Foundation (ishafoundation.org redirects here) | Next.js (React); region/language URLs (`/in/en`); CMS not visible | Cloudflare; files on `static.sadhguru.org` |
| cjp.org.in | Citizens for Justice and Peace, human-rights organisation | WordPress, custom theme `cjp-briefcase`, many plugins | Cloudflare; Jetpack |
| donatekart.com | Product-donation crowdfunding platform | Next.js | nginx 1.22, own servers |
| akshayapatra.org | Akshaya Patra, school mid-day meals NGO | Custom code (likely PHP), Bootstrap/jQuery; agency-built (Creative Yogi) | Cloudflare |
| artofliving.org | The Art of Living (Gurudev Sri Sri Ravi Shankar) | WordPress on Roots Bedrock, custom theme, custom Elementor widgets, WPML, AIOSEO Pro | AWS CloudFront → Varnish → nginx |

Pattern: sites that are mainly content use WordPress; sites that are really applications (accounts,
payments, many regions) are custom-built.

### antaryogfoundation.in

- No WordPress traces. A `<meta name="csrf-token">` tag and Blade-style template whitespace point to
  **Laravel**.
- Front end: Tailwind (CDN), Bootstrap 5, Alpine.js, jQuery, intl-tel-input, jquery-validation.
- Fonts: Plus Jakarta Sans, Noto Serif Devanagari, Sahitya.
- The main site and the blog are two separate systems, which is why their header and footer differ.
  A custom blog theme can match the main site's look.

### isha.sadhguru.org

- Next.js: `__NEXT_DATA__` and `/_next/static` scripts.
- Cloudflare in front; images and files from `static.sadhguru.org`.
- Region and language routing (`/in/en`); content most likely from a separate CMS that the page
  does not reveal.

### cjp.org.in

- Description: "a Human Rights movement dedicated to upholding and defending the freedom and
  constitutional rights of all Indians… our Four Pillars."
- WordPress (`/wp-json/` headers), custom theme `cjp-briefcase`, custom plugin `cjp-bootstrap`;
  `wp.me` short links mean Jetpack.
- Plugins seen: Smart Slider 3, Photo Gallery, Document Gallery, YouTube Embed Plus, Contact Form 7,
  Country-State-City dropdown, Responsive Accordion, testimonials, countdown widget, Toolset Types,
  PhastPress, Jetpack.
- Closest to the proposed setup (WordPress plus a branded theme); the Antar Yog theme would be
  leaner (one stylesheet, the existing importer instead of page-builder plugins).

### donatekart.com

- Donors buy specific products for NGOs' needs. Description: "India's most trusted and transparent
  donation platform… over 1400+ NGOs… products worth 200 crores from 7+ Lakhs unique donors."
- `X-Powered-By: Next.js`, nginx 1.22, Google Tag Manager. Payments and dashboards are behind its
  own backend API, not visible from the homepage.
- A `donatekart-design` skill (colours, typography, components) is installed in this Claude setup
  and could inform the donate button or CTA cards.

### akshayapatra.org

- Description: "dedicated 25 years towards feeding nutritious meals to school children studying in
  Government & Government-aided schools."
- No CMS or framework visible; files from `includes/asset/...` (Bootstrap, jQuery UI, Swiper,
  Slick, Magnific Popup, Font Awesome, Animate.css), typical of a hand-built PHP site (likely PHP,
  not confirmed). Footer credits the agency Creative Yogi. Uses the Depicter slider's files as a
  standalone library.
- Shows that large NGOs often run agency-built custom sites, where content changes depend on
  developers.

### artofliving.org

- Description: "Find solutions for a stress-free and happy life through meditation, yoga and
  breath… based on ancient wisdom from Gurudev Sri Sri Ravi Shankar." The closest match to Antar
  Yog.
- WordPress in a **Roots Bedrock** layout (`/app/themes/`, `/app/plugins/` instead of
  `/wp-content/`): code kept in Git, settings in environment config.
- Custom theme `themes/artofliving`; in-house plugin `elementor_artofliving` (galleries,
  testimonials, teacher listings, popups); `wp_artofliving` with course search.
- WPML (about nine languages, `/in-en` URLs); All in One SEO Pro.
- AWS CloudFront → Varnish → nginx on Ubuntu.

| Art of Living | Antar Yog equivalent |
|---|---|
| `themes/artofliving` | The proposed `antaryog` theme |
| WPML | Polylang (Hindi and English, already set up) |
| AIOSEO Pro | SureRank / Rank Math (importer already writes to them) |
| `elementor_artofliving` widgets | `smd-importer` blocks (Also read, video, figures) |
| CloudFront + Varnish | Cloudflare (already on the blog) |
