## 6. FAQ

**Hindi**
1. **ईश्वर निराकार है तो मूर्ति पूजा क्यों?** क्योंकि हम साकार हैं। जब तक हमारे पास शरीर है, उपासना के लिए सामने भी कोई आकार चाहिए; निराकार की पूजा समाधि की अवस्था में ही सीधे संभव है।
2. **क्या दूसरे धर्मों में भी प्रतीक होते हैं?** हां। आचार्य जी बताते हैं कि क्रॉस, चांद-तारा या परिक्रमा, हर परंपरा किसी प्रतीक का सहारा लेती है; हमारी परंपरा ने उसे कलात्मक आकार दिया।
3. **सांत और अनंत का क्या अर्थ है?** सांत यानी स-अंत, जिसका कहीं अंत है (सीमित); अनंत यानी जिसका अंत नहीं। सांत, अनंत की पूजा सीधे नहीं कर सकता।
4. **क्या निराकार पूजा गलत है?** नहीं। जो समाधि या जीवन्मुक्त अवस्था में है, स्वयं को शरीर से परे जानता है, उसकी निराकार पूजा ठीक है; अन्यथा साकार रूप आवश्यक है।
5. **मूर्ति का स्वरूप कौन तय करता है?** ऋषि-मुनि। मूर्ति मनमाना आकार नहीं, बल्कि उनके दर्शन और अनुभव का नक्शा है।

**English**
1. **If God is formless, why worship a murti?** Because we have form. As long as we live in a body, worship needs a form in front of us; the formless can be worshipped directly only in samadhi.
2. **Do other religions use symbols too?** Yes. Acharya Ji points to the cross, the crescent and star, and circling in pilgrimage: every tradition rests on some symbol. Ours gave it an artistic shape.
3. **What do saant and anant mean?** Saant means "with an end" (finite); anant means without end (infinite). The finite cannot worship the infinite directly.
4. **Is worship of the formless wrong?** No. If you have reached samadhi, the jivanmukta state, and know yourself as beyond the body, worship of the formless is right; otherwise you need a form.
5. **Who decides the form of a murti?** The rishis. A murti is not an arbitrary shape but a map of what they experienced in their vision.

## 10. Authenticity flags

1. **Mecca and Medina (Major, from the Sanskrit review).** Tawaf is performed only around the Kaaba at Mecca, not at Medina. Since the post compares traditions, an inaccuracy here could offend. Recommendation: apply the review's correction ("मक्का में लोग काबा की परिक्रमा करते हैं" / "At Mecca, pilgrims walk in circles around the Kaaba") after checking the transcript; keep it out of titles, metas and snippets until then (it is not used there).
2. **"ऋतम्भरा समाधि" (Minor, review).** In Yoga Sutra 1.48 ऋतम्भरा is the prajna, not a samadhi, and it is not strictly a synonym of kaivalya or jivanmukti. Recommendation: attribute the grouping to Acharya Ji ("आचार्य जी इसे ... कहते हैं") as the review proposes; the FAQ and direct answer avoid the term.
3. **"जीवनमुक्त" spelling (Minor, review).** Standard form is जीवन्मुक्त; the Hindi FAQ already uses it. Fix in the blog body and Key Takeaways.
4. **Indriyas gloss (Minor, review).** Hands and feet are karmendriyas, not sense organs. Recommendation: "(ज्ञानेंद्रियां और कर्मेंद्रियां)" / "(organs of perception and action)".
5. **गुरुदेव / आचार्य जी (Minor, review).** The Hindi uses both; use "आचार्य जी" throughout for consistent entity naming (also helps AI search attribution).
6. **"Idol" keyword pressure.** The most-searched English query uses "idol", which the body never uses and which carries a pejorative history. Recommendation: keep "murti" as the focus keyword (done) and "why do Hindus worship idols" only as a secondary keyword; do not put "idol" in the title. The post's comparison with other religions is respectful and is kept neutral in all meta text; no fear-selling, health or astrological claims found.

## 12. SEO checklist

### Keywords
- [x] Hindi and English each have a focus keyword
- [x] The focus keyword isn't used by another post (no cannibalization)
- [x] 2–4 secondary keywords per language
- [x] Hindi and English keywords researched separately, not translated; Hinglish variants considered
- [x] Focus keyword taken from wording the article already uses
- [x] If people search a different wording, it is in the secondary keywords and the mismatch is flagged
- [x] Priority given as High / Medium / Low, based on intent and competition; no invented numbers

### Focus keyword placement (SureRank)
- [x] In the SEO title
- [x] In the meta description
- [x] In the body text
- [x] In the URL slug (English keywords)
- [x] Within the first 100 words (preferred)

### SEO title
- [x] Present in both languages, ≤ 60 characters
- [x] Keyword near the start
- [x] Faithful to the talk, no clickbait

### Meta description
- [x] Present in both languages, ≤ 160 characters
- [x] English is 140–155 characters
- [x] Gives a clear reason to click

### URL slug
- [x] Lowercase Latin, hyphenated, unique across posts
- [x] Short enough that the full URL stays ≤ 90 characters

### Headings
- [x] At least one subheading (H2)

### Images
- [x] Every image has alt text in both languages
- [x] Alt text is descriptive, in the post's language, based on looking at the image
- [x] Captions add meaning (not a repeat of the alt text or title)

### Internal linking
- [x] Links point only to real posts, never to the same post
- [x] Anchor text is a natural phrase from the body (not a heading or verse)
- [x] 3–5 in-text links per language
- [x] One "Also read" link, placed after the section it extends best
- [x] 3 related posts at the end, the ones that suit this reader best

### Category and tags
- [x] One category, from the approved 14
- [x] 3–6 tags per language
- [x] No tag repeats a category name
- [x] Existing tags reused; no near-duplicates
- [x] Each tag can be shared by at least 3 posts
- [x] No broad labels that only restate a category
- [x] Series tags named exactly as the series
- [x] `festivals` only when the post is about the festival itself; Pitru topics in `pitru`

### Structured data (in this report, not on the page)
- [x] One JSON-LD block per language: BlogPosting, Person, Organization, VideoObject (if there is a video), BreadcrumbList
- [x] Hindi and English versions linked as translations

### Content trust
- [x] Titles, metas and snippets faithful to the talk
- [x] No unsupported scriptural claims
- [x] Health promises, fear-selling and attacks on other traditions flagged

### Not covered
- Live broken links (internal links only work once the linked post is published)
- Canonical and Open Graph tags (SureRank adds these itself)
