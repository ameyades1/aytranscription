## 10. Authenticity flags

Recommendation: apply the review's wording before publishing. Do not write "Gita says go from tamas to rajas to sattva" in any title or snippet.
2. **Only half of Gita 14.10 is quoted (Minor, review).** Mark the reference "पूर्वार्ध / first half" or quote the full verse before the page is marked up as a cited source for AI overviews.
3. **"गुरु गीता में भी यही कहा गया है / The Guru Gita says the same" has no verse cited (review: unverified).** Do not use a Guru Gita claim in the title, meta or FAQ until a verse is identified. FAQ 2 rests only on the blog's own teaching.
4. **Speaker and author.** The talk is a sadhika's account (the video thumbnail names her as Pallavi Dangi); one passage says "आचार्य जी बताते हैं / Acharya Ji explains" (review: check against the transcript). 5. **The Guru taking on the group's halahala and digesting a fever "in a single day".** This is the speaker's personal testimony. Keep it out of titles, meta descriptions and snippets, and never present it as a healing or health claim.
6. **"Every child once knew Shri Vidya" (review: unverifiable).** This is the Guru's statement as reported. The link to the Shri Vidya post is fine, but do not quote the line as a historical fact in SEO copy.

## 12. SEO checklist

This report had no checklist when it was written; it was added with the SEO fix and reflects the `_seo` texts and the current seo.json.

### Keywords
- [x] Hindi and English each have a focus keyword
- [x] The focus keyword isn't used by another post (no cannibalization)
- [x] 2–4 secondary keywords per language
- [x] Hindi and English keywords researched separately, not translated; Hinglish variants considered
- [x] Focus keyword taken from wording the article uses (गुरु सेवा का महत्व / importance of Guru seva, in the `_seo` texts' direct answer)
- [x] If people search a different wording, it is in the secondary keywords and the mismatch is flagged (section 2's keyword note)
- [x] Priority given as High / Medium / Low, based on intent and competition; no invented numbers

### Focus keyword placement (SureRank)
- [x] In the SEO title
- [x] In the meta description
- [x] In the body text
- [x] In the URL slug (English keywords)
- [x] Within the first 100 words (preferred)

### SEO title
- [x] Present in both languages, ≤ 60 characters
- [x] Keyword near the start
- [x] Faithful to the talk, no clickbait

### Meta description
- [x] Present in both languages, ≤ 160 characters
- [x] English is 140–155 characters
- [x] Gives a clear reason to click

### URL slug
- [x] Lowercase Latin, hyphenated, unique across posts
- [x] Short enough that the full URL stays ≤ 90 characters

### Headings
- [x] At least one subheading (H2)
- [x] One H2 phrased as the question readers search ("गुरु पादुका पूजन का सच्चा अर्थ क्या है?" / "What Does Guru Paduka Worship Really Mean?")
- [x] A short direct answer (40–60 words) early in the post

### Images
- [x] Every image has alt text in both languages
- [x] Alt text is descriptive, in the post's language, based on looking at the image
- [x] Captions add meaning (not a repeat of the alt text or title)

### Internal linking
- [x] Links point only to real posts, never to the same post
- [x] Anchor text is a natural phrase from the body (not a heading or verse)
- [x] 3–5 in-text links per language

- [x] Existing tags reused; no near-duplicates
- [x] Each tag can be shared by at least 3 posts
